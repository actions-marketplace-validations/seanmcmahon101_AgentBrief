# AGENTS.md

AgentBrief is a Go CLI that derives verified repository facts for coding agents.
Read `docs/DESIGN.md` before changing behaviour; it is the product spec.

Ground rules for changes:
- Never execute anything from a scanned repository, including `git`. Detectors only parse files.
- Every fact needs a `Source`. A wrong command is worse than no command; when unsure, emit nothing.
- Output must stay byte-for-byte deterministic: no timestamps, absolute paths or map-order iteration.
- Detectors live in `internal/detect/<ecosystem>.go`, register from `init()`, and are tested with `scan.FromMap`.
- New `check` rules need false-positive tests as well as true-positive ones; a CI gate that cries wolf gets deleted.
- Dependencies are the standard library plus BurntSushi/toml and go.yaml.in/yaml/v3. Ask before adding one.
